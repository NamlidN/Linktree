
# 🔗 Linktree

My personal Linktree website.

## 🚀 Features

- Personal profile
- GitHub link
- Contact section
- Responsive design

## 🛠️ Built with

- HTML
- CSS
- JavaScript

## 📦 Installation

Clone the repository:

```bash
git clone git@github.com:NamlidN/Linktree.git
```

Go into the project folder:

```bash
cd Linktree
```

Open `index.html` in your browser.
